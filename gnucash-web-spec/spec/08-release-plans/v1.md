# 08 - Release Plan: v1

## Objective

Harden the current contract and prepare production-grade operational concerns without breaking API compatibility.

## Expected evolution areas

1. Authn/authz and tenant-scoped access control.
2. Stronger auditing (actor, before/after snapshots, change reason).
3. Tax/taxtable behavior specification.
4. Performance SLOs for reporting and large books.
5. Extend contract-level pagination strategy across heavy list endpoints (baseline adopted for `/bills/list`).

## Compatibility policy

- Evolutions SHOULD preserve backward compatibility whenever feasible.
- Breaking changes MUST follow SemVer and changelog policy.
