# Requirements

## Functional
- CRUD for `Book`, `Commodity`, `Account`.
- Account hierarchy operations and validations.
- Pagination, filtering, and tree read.

## Non-Functional
- Reliability: transactional writes; clear error semantics.
- Performance: target latency and throughput.
- Security: auth model (JWT/API key), roles.
- Observability: logs, metrics, health checks.

## Acceptance Criteria
- Enumerate testable outcomes per feature.
